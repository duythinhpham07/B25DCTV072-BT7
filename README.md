Bài tập về nhà Buổi 7 – Lập trình Web (React cơ bản)

Sinh viên: Phạm Duy Thịnh – B25DCTV072

## Bài 1: Virtual Calculator

Thư mục `bai1-virtual-calculator`

- `Display`: hiển thị biểu thức và kết quả
- `Button`: nhận props `label`, `color`
- State lưu biểu thức hiện tại
- Các phép tính + - × ÷, nút C, ⌫ và =

## Bài 2: Trang CV bằng React

Thư mục `bai2-cv-react`

- Các component: `Header`, `Section`, `SkillList`, `ProjectList`, `ProjectCard`, `EducationList`, `Footer`
- Dữ liệu kỹ năng, dự án nằm trong `src/data/cv.js`, truyền xuống component qua props
- `Section` dùng `children`

## Cách chạy

```bash
cd bai1-virtual-calculator   # hoặc bai2-cv-react
npm install
npm run dev
```
